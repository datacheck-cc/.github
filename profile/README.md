# DataCheck (`datacheck.cc`)

Rule-driven, non-AI tabular verification & pre-submission research **Source Data** checklists.  
规则驱动、非 AI 的科研原始数据表与论文附表核查工具，定位来源单元格并输出可复核证据报告。

- **Zenodo Permanent DOI Archive · 学术永久归档：** <https://doi.org/10.5281/zenodo.24524868>

## Verification Boundaries · 使用边界

- Deterministic, rule-driven numerical and structural checks (`XLSX`, `CSV`, `TSV`), available online and as a local Windows desktop application.
- Flagged findings trace directly to original file, sheet, and cell coordinates for human review—never automated verdicts or guarantees.
- Support & inquiries: <mailto:account@datacheck.cc>
